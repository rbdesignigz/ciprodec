Ingresar

Este panel publica directamente en la web. Para entrar hace falta una clave de acceso de GitHub (token) de una cuenta con permiso sobre el repositorio rbdesignigz/ciprodec.

Marcalo solo en una computadora o celular propio.
¿Cómo saco la clave de acceso?
  1. En GitHub, con la cuenta que tiene acceso al repositorio, entrá a Settings → Developer settings → Personal access tokens → Tokens (classic).
  2. Tocá Generate new token (classic). En "Note" poné admin ciprodec y elegí un vencimiento (por ejemplo 90 días).
  3. Marcá solo el permiso public_repo y tocá Generate token.
  4. Copiá la clave (empieza con ghp_) y pegala acá. No la compartas por chat ni por correo.
